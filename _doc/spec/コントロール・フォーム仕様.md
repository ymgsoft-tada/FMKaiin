# コントロール・フォーム仕様

新しいデザインの画面(白基調・半透明パネル)で使う共通部品と、それを使って作ったフォームの仕様をまとめる。

- 1 章: 共通の決まり
- 2 章: 共通部品(Controls / FormHelpers / アイコン一覧)
- 3 章: FormMain2(新トップメニュー)

---

## 1. 共通の決まり

| 項目 | 決まり |
| --- | --- |
| 汎用コントロールの置き場所 | `FMKaiin/Controls/`(名前空間 `App.Controls`) |
| フォーム汎用ヘルパの置き場所 | `FMKaiin/FormHelpers/`(名前空間 `App`) |
| 新規作成時 | 特定の画面に依存しない部品は、上の 2 フォルダのどちらかに入れる。画面固有の処理はフォーム側に書く |
| 寸法の指定 | 自前描画コントロールの寸法プロパティは 96 DPI 基準のピクセル。描画時に `LayoutScale` で拡大する |
| フォームの拡大方式 | `AutoScaleMode.Dpi`。Designer の座標は 115 DPI(表示倍率 120%)基準 |
| フォント | BIZ UDPゴシック。PC に無い場合は `FontFallback` で Meiryo UI に差し替える |
| 文字コード・改行 | 新規ファイル(`.cs` / `.resx` / `.ps1`)は BOM 付き UTF-8・CRLF。既存ファイルは元の文字コードと改行を変えない(`FormFrame.cs` のように LF のファイルがある) |

#### 2.1.1 SideMenuButton

画面の左側に縦に並べる、区分選択用のボタン。`IconButtonBase` を継承し、アイコンと文字列を横並びで表示する。

| プロパティ | 既定値 | 内容 |
| --- | --- | --- |
| `Selected` | false | true のとき選択中の見た目(角丸の塗り + 選択時の文字色)で描く |
| `SelectedFillColor` | 38, 86, 134 | 選択中の塗り色 |
| `SelectedForeColor` | White | 選択中の文字とアイコンの色 |
| `HoverColor` | 230, 240, 248 | 選択していないときの、マウスオーバー時の背景色 |
| `CornerRadius` | 6 | 背景の角の半径 |
| `IconSize` | 22 | アイコンの一辺 |
| `IconLeft` | 14 | 左端からアイコンまでの間隔 |
| `TextGap` | 12 | アイコンと文字列の間隔 |

- 選択していないときは背景を持たない。マウスオーバー時と押下時だけ背景を付ける。
- 「複数のうち 1 つだけ選択」の制御は持たない。どのボタンを選択状態にするかは、置いた画面の側で決める。

**アイコンを追加する手順**

1. `Controls/MenuIconKind.cs` の末尾に名前を追加する。

3. 上のスクリプトで絵を書き出し、この表に行を足す。

## 3. FormMain2(新トップメニュー)

### 3.1 概要

- ログイン後に表示するトップメニュー。`GlassBackdropForm` を継承し、見た目の作りは FormNewMain を踏襲している。
- 左メニューで業務区分(会員登録 / 引き落とし業務 / マスター設定)を選ぶと、右側のボタン一覧がその区分のものに入れ替わる。
- 右側のボタンを押すと、対応する既存画面をモーダル(`ShowDialog`)で開く。
- 既存の FormMain / Form1 / FormReportMenu1 / FormReportMenu2 / FormExcelMenu に分かれていたメニューを、この 1 画面にまとめている。既存のメニュー画面は変更も削除もしていない。
- `Program.cs` は、ログイン後に FormMain2 を表示する。

### 3.3 左メニュー

| 表示名 | コントロール名 | アイコン | 表示するページ |
| --- | --- | --- | --- |
| 会員登録 | `navKaiin` | User | `pnlPageKaiin`(3.4) |

- 選択中の項目は、角丸の濃紺の塗り + 白い文字・アイコンで表示する。「>>」は表示しない。
- 選択していない項目は背景なし。マウスを乗せると淡い色の背景が付く。
- 常にどれか 1 つが選択されている。起動時は「会員登録」。
- クリック、またはフォーカスがある状態で Enter / Space で選択する。選択中の項目をもう一度選んでも何も変わらない。
- 選択すると、右側の見出しの文字(左メニューの表示名と同じ)と、表示するページが入れ替わる。フォーカスは左メニューに残る。

### 3.7 動作

**起動時**

- 「会員登録」を選択した状態で表示し、先頭のボタン(会員データ)にフォーカスを置く。

**メニューボタン**

- クリックで対応する画面を `ShowDialog` で開き、閉じたら破棄する。
- 「銀行」欄が ○ の画面は、開く前に銀行コードを読み込む。読み込みは初回だけ(`AppGlobal.BankCodeMg` が null のとき)で、進捗ダイアログ(`FormBg_Progress`)を表示する。処理内容は FormMain の `initBankCode` と同じ(`t_bank_code` の再取得と `AppGlobal.InitBankCodeMg()`)。
- 「未定義」の項目は、通常の見た目で表示し、押しても何も起きない。

**ツールバー**

| ボタン | コントロール名 | 動作 |
| --- | --- | --- |
| データ保存 | `btnDataSave` | 保存先を選んで DB をバックアップ ファイルへ書き出す。成功したら保存先フォルダを設定(`BackUpDir`)に記憶する |
| データ復旧 | `btnDataRestore` | バックアップ ファイルを選んで DB を復元する。成功したらアプリを再起動する |
| 遠隔サポート | `btnRemoteSupport` | `AppConst.RemoteSupportFilePath` を起動する。起動できなかった場合は何もしない |
| ログアウト | `btnLogout` | 画面を閉じる(アプリが終了する)。確認メッセージは出さない |

データ保存 / データ復旧 / 遠隔サポートの処理は、FormMain の `dataBackup` / `dataRestore` / `execRemote` を移したもの。FormMain との違いは、復旧に失敗した場合もマウス カーソルを通常に戻す点だけ。

**キーボード**

- Tab の順は、ツールバー → 左メニュー → 表示中ページのボタン(左上から右下へ)。
- 表示していないページのボタンにはフォーカスが移らない。

### 3.10 デザイナーで編集するときの注意

3 つのページは同じ位置に重ねて置いてある(どれも `Dock = Fill`)。そのため、デザイナーには一番手前の「会員登録」のページしか見えない。

- ほかのページを編集するときは、「ドキュメント アウトライン」(表示 → その他のウィンドウ)で `pnlPageHikiotoshi` / `pnlPageMaster` を選び、右クリックの「最前面へ移動」で手前に出す。どのページが手前にあっても、実行時の表示には影響しない。
- 「最背面へ移動」は使わない。ページが見出し(`pnlHeading`)やフッター(`pnlFooter`)より後ろに回ると、Dock の配置順が変わり、ページが見出しと重なる。
- ページの `Visible` はデザイナーで変更しない。表示・非表示は `SelectPage` が起動時と切り替え時に設定する。
- 左メニューの `Selected` もデザイナーでは設定しない(同上)。

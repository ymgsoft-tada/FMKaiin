# SControl クイックガイド

## ファイルについて
- comset(branch:control) と、FMKaiin(branch:control) が必要

- comset/UI に S系UI と、それらが使用するクラス

- 名前空間は `ComponentSUI`。フォームの先頭に `using ComponentSUI;` が必要

- S系を直したら、comset と FMKaiin を対でコミットする

- FMKaiin/UpdateForm に S系を使用したフォームとApp

- **dev に置いてしまった不要なファイルを消しています**。FormNewMain の残骸です。

## 新・旧どちらも変更されたもの（変わってしまうもの）
- タイトルバーの色統一（FormMain2 に合わせた）

- ToolTip MsgBox FormBgProgress Indicator FormReportPreview は現在のデザインに合わせた

- アプリアイコン

## 新 で改善されるもの
- S系コントロールにプレースホルダ追加。空欄で「入力必須」と出せる

- S系ラベルに入力必須マーク追加。Required=true で赤い*が出る

- 新規追加画面で、何も入力せずキャンセルしても「入力内容をキャンセル～」と出るが、何も入力してない場合は出ず、何か入力した時だけ出るように変更

- Date の柔軟な入力。R020103 20200103 R02-01-03 R02/01/03 どれでも日付として扱われる

- フリガナや住所の表示が早い

- ほかにもなんかあったけど忘れた……

## FormMain2
```csharp
OpenSideBySideOnClick(btnRepHikiotoshiKakunin, () => new FormOutHikiotoshiKakunin(), () => new FormOutHikiotoshiKakunin2(), needsBankCode: true);
↓
OpenOnClick(btnRepHikiotoshiKakunin, () => new FormOutHikiotoshiKakunin2(), needsBankCode: true);
```

`RegisterMenuActions()` で２つメニューが開く `OpenSideBySideOnClick()` を読んでいる。  
一つだけにするには `OpenOnClick()` に戻す。

## 作業時の注意
- **S系を直した後は、VS でリビルドしてからデザイナーを開く**。古い comset.dll のまま開くと、新しいプロパティの設定が消える

- S系を直したら `sh Test/run.sh` でテスト（一部だけなら `sh Test/run.sh DateHarness`）

### メソッド名の整理

#### 旧
```csharp
// 日付表示コンボボックス
iDispSeireki.ExBeginUpdate();

iDispSeireki.ExAddItem("和暦", false);
```

#### 新
```csharp
// 日付表示のコンボ ボックス
iDispSeireki.BeginUpdate();

iDispSeireki.AddItem("和暦", false);
iDispSeireki.EndUpdate();
```

`Ex` プレフィックスは廃止。それ以外にも、怪しい英語メソッドの名前をリネームしていたりする。

### Gcontrol -> SControl

#### 旧
```csharp
gctl.Add(new GControlDBText(t_basic.FBAS_NameDaihyo, iNameDaihyo));

gctl.Add(new GControlDBPostAddr(
    new string[]{
        t_basic.FBAS_Post,
        t_basic.FBAS_Addr1
    },
    new Control[]{
        iPost1,
        iPost2,
        iAddr1
    }));

gctl.Add(new GControlDBText(t_basic.FBAS_Addr2, iAddr2));
```

#### 新
```csharp
sctl.Add(new SControlDBText(t_basic.FBAS_NameDaihyo, iNameDaihyo));

sctl.Add(new SControlDBPostAddr(
    new string[]{
        t_basic.FBAS_Post,
        t_basic.FBAS_Addr1
    },
    new STextBox[]{
        iPost1,
        iPost2,
        iAddr1
    }));

sctl.Add(new SControlDBText(t_basic.FBAS_Addr2, iAddr2));

```
GControl -> SControl になっただけ。その他は同じ。

### SControlのアップデート、フェッチ

#### 旧
```csharp
gctl.FetchByControl(iBank.ComboBox);

updateCurrentControlValue(gctl);
```

#### 新
```csharp
sctl.FetchByControl(iBank);

sctl.Update();
```
地味だが直感的に使いやすい形に変更されている。`FormFrame.updateCurrentControlValue()` は不要。

### Gc -> S

#### 旧
```csharp
foreach (GcTextBoxEx ctl in ctls)
```

#### 新
```csharp
foreach (STextBox ctl in ctls)
```

**Gc/Uc** 系は今後一切使わない。**S** 系で代用する。

### グリッド・ルール・コンボ

| 旧 | 新 |
| --- | --- |
| `GGridDBCommon` / `GGridDBText` | `SGridDB` / `SGridDBText` |
| `AppDbRule` | `AppSControlRule` |
| `AppTableCombo` / `AppCombo` | `AppSTableCombo` / `AppSCombo` |

名前が変わっただけで、書き方はほぼ同じ。  
入力ルールを変えるときは、旧画面が残っている間は `AppDbRule` と `AppSControlRule` の両方を直す。

画面を移す手順は **S画面仕様.md** の 1.6、配置の決まり（余白・行間）は 1.7 を参照
